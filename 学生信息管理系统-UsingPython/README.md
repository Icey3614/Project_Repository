# 学生信息管理系统

基于 Python + tkinter / **ttkbootstrap** 的图形界面（GUI）学生信息管理系统。数据既可以存放在本机 **MySQL 数据库**，也可以存放在 **Excel 表格**，启动时自动检测并引导选择，无需手动改代码。

## 功能

- **启动自动扫描**：运行后先自动检测本机 MySQL 服务
  - 检测到 MySQL：输入账号密码 → 连接 → 自动创建项目专属数据库 `student_management`
  - 未检测到 MySQL：先让用户选择存放路径 → 在该路径下创建 Excel 数据文件
- **首次/多次使用自动判断**：有数据直接读取使用，无数据自动创建并初始化默认教师账号，不会覆盖已有数据
- **三种登录身份**：进入主界面后选择「学生登录」「教师登录」或「管理员登录」
  - **学生**：凭**学号 + 密码**登录，只读查看本人信息与分年度成绩，可进行成绩对比（必须包含本人），可修改自己的密码
  - **教师**：凭账号 + 密码登录，可对学生信息进行**增、删、改、查**，可查看/对比任意学生成绩，可修改自己的密码
  - **管理员**：拥有教师的全部权限，还可以对**教师账号**进行增删改查，可修改自己的密码
- **初始密码规则**（录入时自动生成）：
  - 学生：**学号 + 身份证后 6 位**
  - 教师：**工号 + 身份证后 6 位**
  - 因此录入学生时需要填写身份证号，录入教师时需要填写工号和身份证号
- **修改密码**：学生、教师、管理员登录后都可以修改自己的登录密码
- **班级维度**：学生可登记班级，教师可按班级筛选与统计
- **成绩统计与排名**：按学年/班级统计总分、平均分、排名、各科平均/最高/最低/及格率（及格线 90 分），并生成平均分对比图
- **回收站**：删除学生先进入回收站，30 天内可恢复，超过 30 天自动彻底清除
- **操作日志**：登录、增删改查、成绩登记、导入导出等操作都会被记录，管理员可查看，并可一键清空全部日志（清空后保留一条审计记录）
- **批量导入**：按模板一次性导入多名学生，自动生成初始密码
- **导出备份**：一键把学生、成绩、教师、日志全部导出为 Excel 文件
- **登录安全**：连续输错密码 5 次锁定 5 分钟；自行设置的新密码至少 6 位且需包含字母和数字
- **身份证脱敏**：教师列表中身份证号只显示前 6 位和后 4 位
- **设置**：登录页、教师端、学生端均可打开「设置」，选择浅色/深色主题与界面语言（简体中文 / 繁體中文 / English / Русский），设置自动保存、下次启动生效（主题采用 ttkbootstrap 的 cosmo / darkly）
- **高分屏适配**：启动时自动开启 DPI 感知，在 150%/200% 缩放的显示器上文字与界面保持清晰，不再模糊/发虚
- **入学年份**：每位学生可登记入学年份
- **分年度成绩登记**：教师可为每名学生登记**每一年**的语数英成绩
- **成绩图表**：学生端与教师端都可以查看，先配置再显示
  - **雷达图**：选择年份后显示该年语文/数学/英语三科成绩
  - **折线图**：选择科目后显示该科目历年的成绩走势
- **多人成绩对比**：同一张雷达图/折线图中同时显示多人数据（不限人数）
  - 学生端对比**必须包含本人**，再选择其他同学
  - 教师/管理员端可以对比任意学生
- **教师账号**：支持多名教师；教师可**修改自己的密码**；管理员可**添加、修改、删除教师账号**
- **搜索**：教师可按学号或姓名模糊查询

## 运行环境

- Windows + Python 3.12（其他 Python 3 版本亦可）
- 依赖：`PyMySQL`、`matplotlib`、`numpy`、`openpyxl`、`ttkbootstrap`
- MySQL 模式需要本机已安装并启动 MySQL；Excel 模式不需要任何数据库

```bash
pip install -r requirements.txt
python main.py
```

如需局域网共享：在向导的 MySQL 登录表单中，把「主机」填为局域网内 MySQL 服务器的 IP 即可（需该服务器允许远程连接）。

## 两种存储方式说明

### MySQL 模式（推荐）

启动时若检测到本机 MySQL（3306 端口可连接），会弹出登录表单。输入账号密码后：

- 自动创建项目专属数据库 `student_management`（若不存在）；
- 自动创建 `students`、`student_scores`、`teachers` 三张数据表；
- 若教师表为空，自动创建默认教师账号 `admin / admin123`；
- 已有学生数据时直接读取，不会清空或覆盖。

### Excel 模式

未检测到 MySQL（或手动切换）时，选择或输入一个存放路径，系统会在该路径下创建四个数据文件：

| 文件 | 内容 |
|---|---|
| `students.xlsx` | 学生信息（学号、姓名、性别、年龄、入学年份） |
| `scores.xlsx` | 分年度成绩（学号、年份、语文、数学、英语） |
| `teachers.xlsx` | 教师账号（密码以盐 + SHA-256 哈希存储） |
| `logs.xlsx` | 操作日志 |

首次使用会创建文件并初始化默认教师账号；再次使用（文件已有数据）会直接读取。教师修改密码、添加学生等操作都会实时写回 Excel 文件。

Excel 模式带有**并发保护**：同一目录的数据文件同时只允许一个程序实例使用，防止数据冲突。

## 默认教师账号

首次使用时自动创建默认**管理员**账号，登录后请及时在「修改密码」中更换：

| 账号 | 密码 |
|---|---|
| admin | admin123 |

教师账号需要由管理员登录后在「教师管理」中创建（可指定角色为“教师”或“管理员”），创建时填写工号和身份证号，初始密码自动生成为**工号 + 身份证后 6 位**。

## 项目结构

```text
学生信息管理系统/
├── main.py            # 程序入口（启动向导 → 主窗口）
├── wizard.py          # 启动向导（检测 MySQL、输入账密/路径、初始化）
├── storage.py         # 存储统一接口 + 字段校验 + 密码哈希
├── mysql_storage.py   # MySQL 存储实现（自动建库建表）
├── excel_storage.py   # Excel 存储实现（openpyxl）
├── login_window.py    # 登录界面（学生/教师/管理员）
├── student_window.py  # 学生个人信息页 + 雷达图/折线图
├── teacher_window.py  # 教师/管理员界面（学生增删改查、成绩登记、对比、教师管理）
├── stats.py           # 成绩统计与排名
├── security.py        # 登录失败锁定
├── ui_style.py        # 浅色/深色主题样式
├── config.py          # 项目常量与默认参数
└── requirements.txt   # 依赖清单
```

（v7.0 起可在 `dist/` 中找到打包好的 `学生信息管理系统.exe`，双击即可运行，无需安装 Python。）

## 注意事项

- 教师密码以“盐 + SHA-256 哈希”形式存储，不保存明文。
- 学生登录凭学号 + 密码，请妥善保管；初始密码由系统按规则生成。
- 删除学生先进入回收站（30 天内可恢复），彻底删除才不可恢复。
- Excel 数据文件是纯文本可编辑的表格，但请勿在程序运行时手动修改，以免数据冲突。
