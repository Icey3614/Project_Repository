# Changelog

## v0.6.0 (2026-08-27)

- 玩法：✨ Wild 万能符号（仅免费转出现，替代除钻石外任意符号）；Scatter 触发免费转（3×3 窗口 ≥3 钻石，不再依赖连线）
- 统计：底部新增实测返奖率（实际赢 / 总下注），与理论 RTP 对照
- 反馈：中奖后新增单局结算明细行（哪条线、什么组合、多少倍）
- 工程：测试收进仓库 `tests/`，`build_exe.ps1` 打包前自动跑测试；新增 GitHub Actions CI 工作流

## v0.5.0 (2026-08-27)

- 新增设置面板（⚙）：音效开关、音量三档（低/中/高，预生成三档音效）、语言、自动转间隔、重置统计
- 所有设置即时生效并自动存档

## v0.4.0 (2026-08-27)

- 交互：AUTO 自动连转（点一下连续拉杆，可随时关闭）与点击滚轮提前停
- 界面：中英文一键切换（按钮或 L 键），语言选择自动保存
- 反馈：中奖时滚轮上金色粒子特效
- 快捷键：A 自动转、L 语言、R 重置、M 静音、+/− 调注

## v0.3.0 (2026-08-27)

- 玩法：5 条赔付线（上/中/下 + 两条对角线）、三个滚轮独立卷带、累积 Jackpot、三钻石触发免费转
- 平衡：赔率/权重/卷带外置到 `config.json`，基础 RTP 约 92%；对子只赔中线低倍符号
- 反馈：中奖数字滚动动画、近失提示、连胜计数、音效资源化（生成 wav）+ 静音开关（M 键）
- 持久化：`save.json` 保存积分/下注/静音/Jackpot/统计，重启不丢失
- 统计：底部显示 Spins / 胜率 / 最高赢 / RTP

## v0.2.4 (2026-08-27)

- 启动时滚轮初始位置改为整数偏移：程序一打开，三个滚轮就各有一个符号精确停在赔付线上

## v0.2.3 (2026-08-27)

- 延长滚轮动画时长（3.5s / 4.5s / 5.5s 逐个停止），单次拉杆到结算约 6 秒，动画更从容
- 启用 Windows 1ms 定时器精度，动画刷新间隔 16ms → 10ms，帧到达更均匀，减少卡顿感

## v0.2.2 (2026-08-27)

- 滚轮速度改为“余弦升速曲线”：起步慢 → 逐渐加速 → 中段达到峰值 → 逐渐减速 → 慢慢停稳
- 符号全程平滑滑动，最终精确停在赔付线上

## v0.2.1 (2026-08-27)

- 优化滚轮停止效果：改为“加速 → 匀速巡航 → 恒定减速度刹停”的物理式速度曲线
- 最后一个符号全程保持可见滑动速度，平滑减速并精确停在赔付线上，不再出现卡顿后跳线
- 停止抖动调小调柔，避免“弹”到线上的观感

## v0.2.0 (2026-08-27)

- 滚轮改为连续卷轴仿真：加速 → 匀速 → 减速 → 停止时轻微抖动，窗口内同时显示上下相邻符号，更像真实老虎机
- 界面紧凑化：整体高度大幅缩小，窗口自动适配屏幕可用高度，不再超出屏幕

## v0.1.0 (2026-08-27)

- 初始版本：三滚轮老虎机，可拖拽拉杆，深色现代 UI
- Windows DPI 感知（Per-Monitor）
- PyInstaller 单文件 exe 打包支持
