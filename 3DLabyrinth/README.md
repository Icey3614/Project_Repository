# 3D 迷宫（3D Labyrinth）

一个用 Python + Pygame 实现的 3D 迷宫游戏，采用经典光线投射第一人称视角（Wolfenstein 风格）。
迷宫分为小 / 中 / 大三档难度，入口在左上角、出口在右下角，走到出口即胜利。

## 运行

需要 Python 3.10+，先安装依赖：

```bash
pip install -r requirements.txt
```

启动游戏：

```bash
python main.py
```

可选参数：

```bash
python main.py --seed 42      # 固定迷宫种子，复现同一迷宫
python main.py --selftest     # 无头自检（生成/渲染/界面验证）
```

## 操作

| 操作 | 按键 |
| --- | --- |
| 前后左右移动 | W / A / S / D（中英文输入法下均有效，方向键也可用） |
| 视角 | 鼠标（移动鼠标转向 / 俯仰） |
| 跳跃（可跳上墙顶） | 空格 |
| 奔跑 | Shift 按住，或双击 W / ↑（自动持续，停止前进约 0.35 秒后退出） |
| 查看二维平面图 | 按住 G（松开关闭，图中标注当前位置、入口、出口） |
| 退出全屏并暂停 | ESC（暂停期间暂停计时，再次按 ESC 回到全屏继续） |
| 暂停时返回主菜单 | M |
| 胜利后 | R 再来一局 · M 主菜单 · ESC 退出 |

说明：

- 键盘输入基于硬件按键状态（`pygame.key.get_pressed`），不经过输入法，因此中英文输入法下 WASD 都有效。
- 游戏启动后会自动解除系统输入法与游戏窗口的关联（`ImmAssociateContext`），即使系统当前是中文输入法，WASD 也直接生效，且不影响其他窗口的输入法。
- 按住空格查看地图期间玩家会暂停移动，松开继续。
- 正式进入游戏后自动切换为全屏；全屏按显示器原生分辨率渲染，保证清晰。
- 程序声明了 DPI 感知（物理像素渲染），不会因 Windows 缩放而模糊。
- 跳跃高度约 1.2 格（墙高 1.0 格），可以跳上墙顶并在墙上正常移动；走出墙缘会坠落回地面。
- 空气墙：无论是跳跃腾空还是站在墙顶，都无法超出迷宫整体边界。
- 助跑 / 奔跑会明显增加跳跃距离（跳跃期间保持水平速度：步行约 3 格、奔跑约 4.6 格）。
- 右下角有常驻小地图（战争迷雾：只有探索过的区域会点亮，含当前位置与朝向、入口/出口标记）。
- 步数统计：每进入一个新格子记一步；各难度最佳成绩（前 5）自动保存到 `%APPDATA%\3DLabyrinth\scores.json`。
- 音效与背景音乐为运行时程序化合成（无需素材文件）。

## 难度与迷宫规模

| 难度 | 单元格规模 | 网格大小 |
| --- | --- | --- |
| 小迷宫（简单） | 11×11 | 23×23 |
| 中迷宫（中等） | 21×21 | 43×43 |
| 大迷宫（困难） | 31×31 | 63×63 |

迷宫使用递归回溯（DFS）算法生成“完美迷宫”：任意两个格子之间只有一条通路，入口到出口必定连通、没有死路成环。每局随机种子，可用 `--seed` 复现。

## 项目结构

```text
main.py           入口（启动参数、自检）
build_exe.bat     一键打包 exe
game/config.py    全局配置（分辨率、难度、手感参数）
game/maze.py      迷宫生成（递归回溯）与查询
game/player.py    玩家移动与碰撞
game/renderer.py  光线投射渲染、纹理贴图、2D 地图叠加
game/app.py       主循环与界面（主菜单 / HUD / 地图 / 胜利画面）
game/scores.py    本地排行榜（JSON 持久化）
game/audio.py     程序化音效与背景音乐
game/selftest.py  无头自检
```

## 打包为 exe

```bash
python -m pip install pyinstaller
build_exe.bat
```

打包产物为 `dist\3DLabyrinth.exe`（单文件、无控制台窗口），可直接双击运行；也可用 `dist\3DLabyrinth.exe --selftest` 做无头自检。

## 设计说明与后续优化方向

- 渲染采用经典光线投射：有 numpy 时使用向量化 DDA（整批列同步推进，性能明显更好），没有 numpy 时自动回退纯 Python 路径；窗口 1280×800（内部渲染分辨率与窗口一致，全屏时与显示器一致，画面锐利）。
- 迷宫、玩家、渲染三个模块相互独立，后续可平滑替换为真 3D 渲染（如 PyOpenGL / Ursina），或继续增强：
  - 道具 / 机关、宝箱、巡逻敌人
  - 通关路径回放（`maze.solve()` 的 BFS 已具备）
  - 更多迷宫生成算法（Kruskal、Prim）与难度细分
- 项目已用 git 管理，初始提交为第一个可玩版本。
