# 贪吃蛇 Snake

用 Python + pygame 实现的贪吃蛇小游戏。

## 功能

- 单人模式：方向键 或 W/A/S/D 均可控制；支持快速连按（方向依次缓冲生效）
- 双人竞技：玩家1 用 W/A/S/D，玩家2 用方向键；一条蛇的蛇头碰到对方身体即判负，
  蛇头相撞时比较双方积分、积分低者判负（积分相同则平局）；可选倒计时（60/90/120/180 秒），
  时间到按积分定胜负
- 豆子持续刷新：单人/双人开局都有多颗豆子，之后每隔约 2 秒自动随机新增一颗，
  数量没有固定上限——不去吃也会不断冒出来（直到棋盘被占满）
- 按键输入法兼容：程序同时监听按键事件、pygame 轮询和 Windows 物理按键，
  中文输入法开启时 W/A/S/D、P、M 等键同样有效
- 游戏设置（自动保存到 `config.json`）：
  - 游戏模式：单人游戏 / 双人竞技
  - 双人倒计时：开 / 关，以及倒计时时长
  - 地图大小：小地图 (15×15) / 中地图 (20×20) / 大地图 (30×20)
  - 移动速度：3 ~ 20 格/秒
  - 允许穿墙：开启后撞到边界会从对侧钻出；关闭时撞墙即游戏结束
  - 随长度加速：开启后每吃一个食物速度逐渐提升（最高为基础速度的 2 倍）
- 游戏侧栏：虚拟方向键、速度 / 穿墙 / 加速可实时调整，双人倒计时醒目显示
- 高分屏适配：进程级 DPI 感知，窗口与文字按系统缩放比例渲染，文字清晰不模糊
- 现代化界面：深色主题、圆角卡片、渐变背景、按钮悬停效果、应用图标
- 暂停 / 继续：P 或 空格
- 重新开始：R
- 返回主菜单：M 或 Esc

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## 打包为 exe

直接双击 `build.bat`，或在命令行执行：

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name Snake --icon assets/icon.ico --add-data "assets/icon.png;assets" main.py
```

打包产物位于 `dist/Snake.exe`。

## 测试

```bash
python -m unittest discover -s tests
```
