# LED 电子横幅（Python 模拟）

用 Python 模拟街头常见的黑色 LED 点阵电子横幅：文字以红色点阵形式在黑底上滚动，支持直接播放 Word 文档内容。

## 运行

```bash
python main.py                                # 默认滚动：你好，世界！
python main.py --content "开张大吉 欢迎光临"  # 自定义内容
python main.py --speed 50                     # 调整滚动速度（列/秒）
python main.py --direction right              # 向右滚动
```

### 可选参数

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--content` | 滚动内容 | 读配置，默认你好，世界！ |
| `--rows` | 点阵行数 | 32 |
| `--cols` | 点阵列数 | 192 |
| `--cell` | 初始 LED 间距（像素） | 8 |
| `--fps` | 刷新率 | 25 |
| `--speed` | 滚动速度（列/秒） | 读配置，默认 30 |
| `--direction` | 滚动方向（left/right） | 读配置，默认 left |
| `--preview` | 渲染一帧预览 PNG 后退出 | 无 |
| `--selftest FILE` | 测试读取指定文档后退出 | 无 |

### 鼠标与键盘操作

- 鼠标左键：暂停 / 继续
- 鼠标右键：打开设置窗口
- `空格`：暂停 / 继续
- `+` / `-`：加快 / 减慢
- `Esc`：退出

### 设置窗口（右键打开）

- 移动速度：5~200 列/秒
- 滚动方向：向左 / 向右
- 默认显示内容：下次启动时自动使用
- 选择 Word 文件播放：读取本机 `.docx`（或 `.txt`）文档并滚动播放其中的文字
- 恢复默认内容：停止 Word 内容，切回默认文字

设置会在点击“保存”后写入 `banner_config.json`（exe 所在目录），下次启动自动生效。
设置窗口关闭后，再次右键即可重新打开。

设置界面为深色主题，程序已启用 DPI 感知，在高分屏/系统缩放下文字清晰不发虚。

## 窗口缩放

横幅按等比例放大/缩小：拖动窗口（或最大化）时，整块点阵会同步缩放铺满窗口，
不会出现多余的大片黑色区域。窗口高度随比例缩放，始终保持横幅比例。

## 显示效果

- 点阵为 32×192，字形分辨率更高、更清晰
- 字形二值化（亮 / 灭两态），去掉暗红中间色，边缘更锐利
- 渲染分块进行，超长文本也不会触发 Pillow 像素上限；内容超过 3000 字时自动截取并提示

## 性能

- 滚动采用“增量渲染”：每帧全量比对点阵状态，只更新发生变化的 LED（通常每帧仅几十颗）
- 正常滚动每秒可处理数万帧逻辑，远高于 25 帧/秒的显示需求，运行流畅
- 窗口缩放时点阵重建有防抖，不会频繁卡顿

## 打包为 exe

```bash
python -m PyInstaller --onefile --windowed --name LEDBanner main.py
```

生成的单文件程序位于 `dist/LEDBanner.exe`。

## 问题排查

- Word 文档读不出来：先运行 `dist\LEDBanner.exe --selftest 你的文档.docx` 看能否读取
- 文档过长：横幅会自动截取前 3000 字播放（会在设置窗口提示）
- 出错时程序会在 exe 同目录写 `banner.log`，可把内容发来排查

## 预览

`python main.py --preview preview.png` 可生成一帧静态预览图。
