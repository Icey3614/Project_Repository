# 仿真雷达（Simulation Radar）

一个用 Python + Tkinter 编写的雷达仿真小程序。窗口中的雷达圆盘代表整块屏幕，圆心代表屏幕中心；扫描线持续顺时针旋转，同时实时捕捉鼠标位置。只有扫描线“扫过”鼠标所在方位之后，该位置才会以亮点（回波）形式点亮，然后按雷达余辉效果逐渐衰减消失。

## 功能

- 雷达圆盘 = 屏幕，圆心 = 屏幕中心（鼠标位置按比例映射到圆盘上）
- 扫描线持续顺时针旋转（永不暂停），默认 12 转/分钟（5 秒一圈），可用 `--rpm` 调整
- 通过 ctypes 直接读取系统鼠标位置，无第三方运行时依赖
- 扫描线扫过鼠标后，以亮红色圆点标记；红点常亮，约 3 秒后熄灭
- 运动中的鼠标同样可捕捉：只要鼠标（无论运动还是静止）与扫描线重合，就立即读取并显示在雷达上
- DPI 感知：在高分屏上界面清晰不发虚（按系统 DPI 缩放窗口与字体）
- 界面不显示任何文字信息（无 X/Y、方位角等），只保留雷达本身
- 默认窗口尺寸为原版的 1/3（213 逻辑像素，可用 `--size` 调整），运行后自动显示在屏幕右上角
- 鼠标超出屏幕内切圆时按雷达边缘吸附显示
- 运行异常不会中断扫描，错误会记录到 `%TEMP%\radar_error.log`

## 运行

需要 Python 3.9+（自带 tkinter，无需安装第三方包）：

```text
python main.py
```

可选参数：

```text
python main.py --size 800 --rpm 12
```

## 打包为 exe

```text
python -m PyInstaller --noconfirm --clean --onefile --windowed --name Radar main.py
```

也可以直接运行 `build.ps1`。生成的 exe 位于 `dist/Radar.exe`，双击即可运行。

## 测试

```text
python tests/test_core.py
```

## 版本管理

本项目使用 git 管理，每个版本打 tag 标记（如 `v0.1.0`）。

- v0.1.0：初始版本 —— 雷达扫描 + 鼠标跟踪 + 回波余辉 + exe 打包
- v0.2.0：修复“扫到鼠标后扫描暂停”的缺陷；回波改为红色闪烁标记（约 4 秒消失）；增加 DPI 感知
- v0.3.0：回波统一为亮红色（去掉白色内芯）；闪烁频率降低至约 2Hz；扫描速度改为 5 秒一圈；HUD 移至边框与圆盘之间
- v0.4.0：取消闪烁，红点改为常亮、约 3 秒后熄灭；支持运动中鼠标的捕捉（与扫描线重合即点亮）
- v0.5.0：去掉扫描线末端的端点小圆点，仅保留扫描线本身
- v0.6.0：窗口缩小至原尺寸的 1/3；移除 HUD 文字信息，只保留雷达；运行后自动定位屏幕右上角
