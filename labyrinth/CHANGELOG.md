# 更新日志

## v1.4.2 - 2026-08-14

- 项目整理：清理构建产物与临时图片，README 去除本地绝对路径
- 打包脚本构建后自动将 exe 复制到项目上一级目录，便于分发
- 新增 .gitattributes 统一换行符，为 GitHub 上传做准备

## v1.4.1 - 2026-08-14

- 修复：点击工具栏按钮后，空格键会触发按钮点击的问题
- 工具栏按钮/下拉框/勾选框不再接收键盘焦点，空格键只控制色块移动
- 种子输入框增加数字校验，避免误输入

## v1.4.0 - 2026-08-14

- 自动寻路过程中可再次点击其他位置，色块立即改为前往新目标
- 空格暂停后可点击选择新目标，再次按空格后移动到新目标
- 空格暂停中可用方向键手动移动色块，移动后自动清空原寻路记录并退出暂停

## v1.3.0 - 2026-08-14

- 迷宫随窗口大小等比缩放并居中：最大化/拖动窗口时迷宫同步放大缩小，不再贴左
- 按下空格键暂停/继续色块移动动画
- 新增“显示移动轨迹”开关：勾选后色块走过的格子标记颜色；取消勾选轨迹消失并清空记录，再次勾选后重新开始记录

## v1.2.0 - 2026-08-14

- 界面优化：启用 Windows DPI 感知，字体与画面不再模糊；墙体改为矩形填充绘制，消除马赛克感
- 绿色色块可用方向键（↑↓←→）移动，需沿迷宫通道行走，不能穿墙
- 绿色色块到达红色终点时弹出“寻路成功”提示框，可选择“下一场游戏（重新生成）”或“关闭”
- 主界面“重新生成迷宫”按钮改为先确认再生成，避免误触丢失当前进度
- 点击迷宫任意位置，绿色色块自动沿最短路径移动过去；无法到达时提示“此路不通”

## v1.1.1 - 2026-08-14

- 修复 windowed exe 在命令行模式下 stdout/stderr 为 None 导致的崩溃
- 重新打包 dist/MazeGenerator.exe

## v1.1.0 - 2026-08-14

- 新增 tkinter 图形界面：规模下拉框、随机种子输入、算法切换、一键重新生成、保存图片
- 新增打包脚本 build_exe.bat / build_exe.ps1，输出 windowed 单文件 exe
- 新增 README 与 CHANGELOG

## v1.0.0 - 2026-08-14

- 初始版本：两种完美迷宫生成算法（递归回溯 / 随机 Prim）

- Pillow 平面俯瞰 PNG 渲染，起点/终点标记
- 命令行：generate / gui
- 单元测试：生成正确性、种子可复现、渲染尺寸
