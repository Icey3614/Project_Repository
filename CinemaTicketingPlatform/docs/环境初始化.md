# 环境初始化

> 目标：初始化后 10 分钟内跑起前后端
> 端口约定：MySQL 3306、后端 8000、前端 5173

## 0. 目录结构

- backend/：FastAPI 后端
- frontend/：React 前端
- docs/：项目文档
- README.md

## 1. 前置条件（本机已具备）

- Node.js >= 20（本机 v24.19.0）
- Python 3.12（本机 3.12.10）
- MySQL 8.0（本机 MySQL80 服务已运行）
- Git

## 2. 数据库

```sql
CREATE DATABASE cinema_platform DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'cinema_app'@'localhost' IDENTIFIED BY '<password>';
GRANT ALL PRIVILEGES ON cinema_platform.* TO 'cinema_app'@'localhost';
```

本地开发亦可直接使用 root 账号。表结构由 Alembic 迁移管理，不手工建表。

## 3. 后端初始化

```powershell
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # 填写数据库与 JWT 配置
alembic upgrade head        # 执行迁移
python -m app.seed          # 种子数据
uvicorn app.main:app --reload --port 8000
```

验证：访问 http://localhost:8000/docs

## 4. .env 模板（.env.example）

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=cinema_app
DB_PASSWORD=change_me
DB_NAME=cinema_platform
JWT_SECRET=change_me_strong_random
JWT_EXPIRE_MINUTES=120
CORS_ORIGINS=http://localhost:5173
PAYMENT_PROVIDER=mock
# 支付宝沙箱（申请后填写）
ALIPAY_APP_ID=
ALIPAY_PRIVATE_KEY=
ALIPAY_PUBLIC_KEY=
ALIPAY_NOTIFY_URL=
ALIPAY_RETURN_URL=http://localhost:5173/me
ALIPAY_GATEWAY=https://openapi-sandbox.dl.alipaydev.com/gateway.do
SCHEDULER_ENABLED=true
TZ=Asia/Shanghai
```

.env 不入库；.env.example 入库。

### 支付渠道切换

- `PAYMENT_PROVIDER=mock`：开发期免登录，下单后点支付立即成功
- `PAYMENT_PROVIDER=alipay`：走支付宝沙箱，前端跳转沙箱收银台；支付完成后回到 `ALIPAY_RETURN_URL`，在"我的电影票-待支付"里点"刷新状态"即可同步（无需公网回调）；部署到有公网地址的环境后配置 `ALIPAY_NOTIFY_URL` 启用异步回调

沙箱测试需要登录 [支付宝开放平台沙箱](https://open.alipay.com) 获取沙箱买家账号（手机号/密码），在沙箱收银台完成支付。

## 5. 前端初始化

```powershell
cd frontend
pnpm install
copy .env.development.example .env.development   # 配置 VITE_API_BASE
pnpm dev
```

.env.development.example：

```ini
VITE_API_BASE=http://localhost:8000/api/v1
```

## 6. Git 初始化

- 项目根目录执行 git init
- .gitignore 覆盖：Python（.venv/、__pycache__/、*.pyc）、Node（node_modules/、dist/）、.env、IDE 目录
- 首次提交：目录骨架 + 全部文档

## 7. 种子数据（app/seed.py）

- 管理员：admin / Admin@123456（首次登录后提示修改）
- 演示用户：demo / Demo@123456
- 3 部电影（含海报占位与时长）
- 2 个场馆：8 排 x 12 列、10 排 x 14 列，含屏幕/出入口位置与部分禁用座位

- 幂等：重复执行不产生重复数据（存在即跳过）

## 8. 常见问题

- MySQL 认证：8.0 默认 caching_sha2_password，需安装 pymysql + cryptography
- 端口冲突：8000/5173 被占用时调整配置
- 时区：统一 Asia/Shanghai，写入 .env 的 TZ
- 定时任务：本地开发 SCHEDULER_ENABLED=true；测试环境可关闭
- 支付宝验签：应用私钥用于签名请求，支付宝公钥用于验证回调/响应，两者不是一对，不能互相验签

## 9. 桌面版（分享用）

可将项目打包为免安装的 Windows 桌面应用（Electron + 内置后端）。运行后首次配置向导会：
检测本机 MySQL → 输入本机数据库用户名/密码 → 自动建库建表种子 → 输入自己的支付宝沙箱信息（或使用模拟支付）。
配置保存在 `%APPDATA%\CinemaTicketingPlatform\config.json`。构建方式见 README「桌面版」一节。
