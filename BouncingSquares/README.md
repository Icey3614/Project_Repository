# 碰撞方块小程序（Bouncing Squares）

一个 Python 实现的**电脑桌宠**：方块直接悬浮在屏幕上沿直线运动，碰到
屏幕边界时反弹，支持多个方块、重力、逐方块配置等丰富功能。

## 功能特性

- 透明、无边框、铺满整个屏幕并置顶的桌宠窗口，方块区域可点击、其余区域
  鼠标穿透
- 多显示器支持：自动感知全部显示器的实际边界（含扩展屏、任意摆放），
  并支持热插拔自适应（运行中接入/拔掉显示器约 1 秒内自动适配）
- 多个方块：初始集中排列、互不重叠、带序号；互相弹性碰撞（动能守恒，
  接触瞬间反弹、无重叠）；可随时追加或按序号删除（自动重新编号）
- 逐方块配置：每个方块可单独设置大小、速度、方向、颜色与重量
  （重量影响碰撞：越重越能推动轻方块）
- 全局重力：勾选后受重力下落、落地完全弹性反弹（无能量衰减）
- 交互：点击暂停/继续、拖动（运动中按最后方向飞出，暂停中只移动位置）、
  右键设置弹窗、空格键暂停并弹出设置界面、任务栏最小化记忆状态
- 设置界面使用 ttkbootstrap 现代扁平主题，支持色盘选色与随机变色

## 运行环境

- Windows 10 / 11（桌宠窗口依赖 Windows 特性）
- Python 3.8+（标准版自带 Tk）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行方式

```bash
python main.py
```

双击 `run.bat` 也可以（出错时窗口会保留并显示错误信息）。
跳过设置框快速启动（使用默认参数）：`python main.py --auto`。

## 设置说明

| 设置项 | 含义 |
| --- | --- |
| 方向 | 角度制，0°=向右、90°=向下（屏幕坐标系，y 轴向下）；也可勾选"随机方向" |
| 边长 | 方块的边长，单位：像素（10 ~ 1000） |
| 速度 | 方块每秒移动的距离，单位：像素/秒（10 ~ 5000） |
| 数量 | 方块个数（1 ~ 20），初始集中在屏幕中央、互不重叠，每个带序号 |
| 颜色 | 色盘上按住可跟随鼠标选色（点击也可选定）；也可勾选"随机颜色"，运动中自动变色、暂停时不变 |
| 全局重力 | 勾选后方块受重力下落、落地完全弹性反弹；不勾选则匀速直线运动 |

数量大于 1 时，设置界面下方会出现**逐方块配置**：选择方块序号后可单独
设置该方块的大小、速度、方向、颜色与重量（应用后该方块不再跟随全局参数，
可随时恢复为"跟随全局"）。运行中右键方块弹出的调整窗口里同样支持。

## 运行中的操作

- 任务栏图标：单击最小化（记住状态）、再单击恢复继续运动
- 空格键：运动中按空格立即暂停并弹出设置界面；暂停时按空格的行为可在
  设置界面里选择（无操作 / 继续运行）
- 左键点击方块：暂停 / 继续
- 按住方块拖动：运动中松手按最后方向继续飞；暂停中只移动位置
- 右键点击方块：弹出调整设置（大小/速度/方向/颜色/重量、追加/删除方块、
  退出程序）
- 任务栏图标右键 → 关闭，或按 `Esc`：退出程序

## 打包成 exe

使用 PyInstaller 打包为单文件 exe（无需安装 Python 即可运行）：

```bash
python -m PyInstaller --noconfirm --clean --onefile --noconsole --name "BouncingSquares" --icon icon.ico --version-file version_info.txt --add-data "icon.ico;." --collect-data ttkbootstrap main.py
```

打包产物位于 `dist\BouncingSquares.exe`。重新打包前建议删除 `build\` 与
`dist\` 目录。`BouncingSquares.spec` 为打包配置，已纳入版本管理。

## 项目结构

```text
BouncingSquares/
├── main.py            # 程序入口：先弹设置框，再启动桌宠动画
├── settings_dialog.py # 设置窗口（方向/大小/速度/数量/重力/颜色/逐方块配置）
├── app.py             # 桌宠动画主程序（运动、碰撞、拖拽、方块管理）
├── win_utils.py       # Windows 窗口样式工具（透明/无边框/鼠标穿透/多屏）
├── run.bat            # 双击启动脚本
├── icon.ico           # 程序图标
├── version_info.txt   # exe 版本信息
├── requirements.txt   # 依赖
├── BouncingSquares.spec  # PyInstaller 打包配置
└── README.md
```
